# K8sGuard Graph Milestone V3

## Scope
Replaces the previous oversized resource-card graph with a compact, K8sGuard_Console.html-inspired graph: circles for workloads/ServiceAccounts, diamond bindings, rectangular roles/secrets, hexagons for CRDs/other special resources, colored and dashed directed links, cross-namespace highlighting, hover focus, node dragging, panning, zooming, legend, and resource inspector.

## Data authenticity
The Attack Graph tab displays a clearly marked SAMPLE FIXTURE until a YAML or live scan is completed. It uses the existing `evaluation/results/operator_and_paths.json` generated by backend analysis of `fixtures/operator_and_paths.yaml`; it does NOT claim this is a live cluster. Once a scan is completed, the graph uses API-provided nodes/edges and the NetworkX coordinates in `graph_layout` if present. Any omitted positions use a visual-only deterministic fallback; they do not change backend graph edges. Backend scanner and live endpoint are unchanged. The `503` cluster error is not fixed by this UI update.

## Methodology
The visualization is inspired by the reference but is not a copy of the reference's hardcoded simulated demonstration model; it operates on the K8sGuard analyzer output. MITRE/CIS semantic edges may be present in scan data and can render as generic resource types. Attack paths are conditional inferences, not validated exploits.
